# Subagent Team Presets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@kreeger/pi-subagent-teams`, a globally installable Pi package that lets the user select session-scoped subagent model presets through `/team` commands and exact natural-language aliases.

**Architecture:** A small Pi extension owns global config loading, validation, commands, input transforms, session-entry state, live local-provider probes, and per-turn system guidance. A bundled `subagent-teams` skill teaches the parent model to call `subagent({ action: "list" })`, select role exceptions, and pass exact model IDs to native child launches. The package deliberately remains best-effort because it does not modify `pi-subagents` internals or intercept direct/nested child launches.

**Tech Stack:** TypeScript ES modules, `@earendil-works/pi-coding-agent` extension APIs, Vitest, Node built-ins, npm Pi package resources.

**Spec:** `docs/superpowers/specs/2026-08-25-subagent-team-presets-design.md`

## Global Constraints

- Read `docs/superpowers/specs/2026-08-25-subagent-team-presets-design.md` before implementing any task.
- Keep `normal` built-in and pass-through; never mutate `~/.pi/agent/settings.json`, `~/.agents`, project config, agent files, or the parent model.
- Store only preset names and resolved model snapshots in session entries; never persist API keys or provider credentials.
- Require fully qualified `provider/model` targets, including `localllm-orm/Qwen/Qwen3.6-35B-A3B-FP8`.
- Fail activation without changing active state when selected model validation or local probing fails.
- Treat direct/nested `subagent` launches as bypassable; never claim hard enforcement.
- Use the existing `subagent({ action: "list" })` guidance path rather than pretending another extension can call the LLM tool or an unavailable agent-list RPC.
- Preserve role configuration; normalize unsupported thinking to `off` only in the model-facing routing guidance.
- Leave `external-cli` and `external-job` runners unchanged and report them as skipped.
- Run focused tests after each task and commit each independently testable deliverable.
